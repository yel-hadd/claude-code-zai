How to switch

  1. Subscribe to the GLM Coding Plan (referral link, 10% off your first subscription) and create an API key in your z.ai account.
  2. Run the one-line installer below and paste the key when asked.
  3. Open a new terminal and run claude-z in your project.

GLM-5.3 is a different model from Claude, so results will differ. Run your usual tasks through both before you cancel anything. z.ai's FAQ says Coding Plan subscriptions are non-refundable once purchased.

Manual setup

Everything the installers put in ~/.claude-z, if you'd rather set it up by hand. Make the .sh files executable with chmod +x, and on Linux and macOS install jq.

~/.claude-z/zai-quota.sh: reads the quota, cached for 60 seconds 
#!/usr/bin/env bash
# z.ai GLM Coding Plan quota, from https://api.z.ai/api/monitor/usage/quota/limit
# Usage: zai-quota.sh [--short|--full|--json]   (cached 60s in ~/.cache/zai-quota.json)
# https://github.com/yel-hadd/claude-code-zai
mode="${1:---short}"
cache="${XDG_CACHE_HOME:-$HOME/.cache}/zai-quota.json"
key="${ZAI_API_KEY:-$(cat "$HOME/.config/zai/api_key" 2>/dev/null)}"
[ -n "$key" ] || { echo "z.ai: no key"; exit 0; }

mkdir -p "$(dirname "$cache")"
if [ ! -s "$cache" ] || [ $(( $(date +%s) - $(stat -c %Y "$cache" 2>/dev/null || stat -f %m "$cache") )) -ge 60 ]; then
  tmp="$cache.$$"
  if curl -s -m 5 https://api.z.ai/api/monitor/usage/quota/limit \
       -H "Authorization: Bearer $key" -H "Accept-Language: en-US,en" -o "$tmp" \
     && jq -e '.success == true' "$tmp" >/dev/null 2>&1; then
    mv "$tmp" "$cache"
  else
    rm -f "$tmp"
  fi
fi
[ -s "$cache" ] || { echo "z.ai: quota unavailable"; exit 0; }

case "$mode" in
  --json) cat "$cache" ;;
  --short)
    # unit 3 = hours, 6 = weeks, 5 = months; nextResetTime is epoch ms
    jq -r '
      def win: if .unit == 3 then "\(.number)h" elif .unit == 6 then "wk" elif .unit == 5 then "mo" else "u\(.unit)" end;
      def reset: if .nextResetTime then " ↻" + ((.nextResetTime / 1000) | strflocaltime("%a %H:%M")) else "" end;
      [.data.limits[] | select(.type != "TIME_LIMIT") | "\(win) \(.percentage)%" + (if .percentage >= 80 then reset else "" end)]
      | join(" · ")' "$cache" ;;
  --full)
    jq -r '
      def win: if .unit == 3 then "\(.number)-hour window" elif .unit == 6 then "Weekly" elif .unit == 5 then "Monthly" else "unit \(.unit) x\(.number)" end;
      "z.ai plan: \(.data.level)",
      (.data.limits[] |
        "\(win) (\(.type)): \(.percentage)% used, \(.currentValue // 0) of \(.usage // "?"), \(.remaining // "?") left" +
        (if .nextResetTime then ", resets \((.nextResetTime / 1000) | strflocaltime("%a %b %d %H:%M %Z"))" else "" end))' "$cache" ;;
esac
~/.claude-z/statusline.sh: the status line 
#!/usr/bin/env bash
# claude-z status line: model · context used · z.ai quota
# https://github.com/yel-hadd/claude-code-zai
input="$(cat)"
model="$(jq -r '.model.display_name // .model.id // "GLM"' <<<"$input")"
ctx="$(jq -r '.context_window.used_percentage // empty | floor' <<<"$input" 2>/dev/null)"
quota="$("$(dirname "$0")/zai-quota.sh" --short)"
printf '%s' "$model"
[ -n "$ctx" ] && printf ' · ctx %s%%' "$ctx"
printf ' · %s\n' "$quota"
~/.claude-z/hooks/zai-usage-hook.sh: answers /zai-usage without calling the model 
#!/usr/bin/env bash
# UserPromptSubmit hook: answer /zai-usage locally, without calling the model,
# so it still works when the z.ai quota is exhausted.
# https://github.com/yel-hadd/claude-code-zai
prompt="$(jq -r '.prompt // empty')"
case "$prompt" in
  /zai-usage|/zai-usage\ *)
    out="$("$(dirname "$0")/../zai-quota.sh" --full 2>&1)"
    jq -n --arg r "$out" '{decision: "block", reason: $r}'
    ;;
esac
exit 0

# claude-z: Claude Code on the z.ai GLM Coding Plan (PowerShell 5.1 and 7).
# Dot-sourced from $PROFILE. Key lives in ~/.config/zai/api_key (owner-only ACL).
# https://github.com/yel-hadd/claude-code-zai
# No GLM Coding Plan yet? https://z.ai/subscribe?ic=BY27XR8RLD (referral link, 10% off your first subscription)

function claude-z {
  $keyFile = Join-Path $HOME '.config\zai\api_key'
  if (-not (Test-Path $keyFile) -or -not "$(Get-Content $keyFile -Raw)".Trim()) {
    Write-Host "No GLM Coding Plan yet? https://z.ai/subscribe?ic=BY27XR8RLD (referral link, 10% off your first subscription)"
    Write-Error "claude-z: missing z.ai key in $keyFile"; return
  }
  $key = (Get-Content $keyFile -Raw).Trim()
  $vars = @{
    CLAUDE_CONFIG_DIR                        = Join-Path $HOME '.claude-z'
    ANTHROPIC_BASE_URL                       = 'https://api.z.ai/api/anthropic'
    ANTHROPIC_AUTH_TOKEN                     = $key
    ZAI_API_KEY                              = $key
    API_TIMEOUT_MS                           = '3000000'
    ANTHROPIC_MODEL                          = 'glm-5.3[1m]'
    ANTHROPIC_DEFAULT_OPUS_MODEL             = 'glm-5.3[1m]'
    ANTHROPIC_DEFAULT_SONNET_MODEL           = 'glm-5.3[1m]'
    ANTHROPIC_DEFAULT_HAIKU_MODEL            = 'glm-5.3-flash[1m]'
    CLAUDE_CODE_SUBAGENT_MODEL               = 'glm-5.3[1m]'
    CLAUDE_CODE_AUTO_COMPACT_WINDOW          = '1000000'
    CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC = '1'
  }
  $saved = @{}
  foreach ($name in $vars.Keys) {
    $saved[$name] = [Environment]::GetEnvironmentVariable($name, 'Process')
    [Environment]::SetEnvironmentVariable($name, $vars[$name], 'Process')
  }
  try { claude @args }
  finally {
    foreach ($name in $saved.Keys) {
      [Environment]::SetEnvironmentVariable($name, $saved[$name], 'Process')
    }
  }
}

~/.claude-z/zai-quota.ps1: reads the quota, cached for 60 seconds 
# z.ai GLM Coding Plan quota, from https://api.z.ai/api/monitor/usage/quota/limit
# Usage: zai-quota.ps1 [-Mode Short|Full|Json]   (cached 60s in %TEMP%\zai-quota.json)
# https://github.com/yel-hadd/claude-code-zai
param([ValidateSet('Short', 'Full', 'Json')][string]$Mode = 'Short')

[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12

$key = $env:ZAI_API_KEY
$keyFile = Join-Path $HOME '.config/zai/api_key'
if (-not $key -and (Test-Path $keyFile)) { $key = "$(Get-Content $keyFile -Raw)".Trim() }
if (-not $key) { 'z.ai: no key'; return }

$tmpDir = if ($env:TEMP) { $env:TEMP } else { [IO.Path]::GetTempPath() }
$cache = Join-Path $tmpDir 'zai-quota.json'
if (-not (Test-Path $cache) -or ((Get-Date) - (Get-Item $cache).LastWriteTime).TotalSeconds -ge 60) {
  try {
    $r = Invoke-RestMethod -Uri 'https://api.z.ai/api/monitor/usage/quota/limit' -TimeoutSec 5 `
      -Headers @{ Authorization = "Bearer $key"; 'Accept-Language' = 'en-US,en' }
    if ($r.success) { $r | ConvertTo-Json -Depth 6 | Set-Content -Path $cache -Encoding UTF8 }
  } catch { }
}
if (-not (Test-Path $cache)) { 'z.ai: quota unavailable'; return }
if ($Mode -eq 'Json') { Get-Content $cache -Raw; return }

$q = Get-Content $cache -Raw | ConvertFrom-Json

# unit 3 = hours, 6 = weeks, 5 = months; nextResetTime is epoch ms
function Format-Reset($limit, $format) {
  [DateTimeOffset]::FromUnixTimeMilliseconds([int64]$limit.nextResetTime).ToLocalTime().ToString($format)
}

if ($Mode -eq 'Short') {
  $parts = foreach ($l in $q.data.limits) {
    if ($l.type -eq 'TIME_LIMIT') { continue }
    $w = switch ($l.unit) { 3 { "$($l.number)h" } 6 { 'wk' } 5 { 'mo' } default { "u$($l.unit)" } }
    $s = "$w $($l.percentage)%"
    if ($l.percentage -ge 80 -and $l.nextResetTime) { $s += ' resets ' + (Format-Reset $l 'ddd HH:mm') }
    $s
  }
  $parts -join ' | '
} else {
  "z.ai plan: $($q.data.level)"
  foreach ($l in $q.data.limits) {
    $w = switch ($l.unit) { 3 { "$($l.number)-hour window" } 6 { 'Weekly' } 5 { 'Monthly' } default { "unit $($l.unit) x$($l.number)" } }
    $used = if ($null -ne $l.currentValue) { $l.currentValue } else { 0 }
    $line = "$w ($($l.type)): $($l.percentage)% used, $used of $($l.usage), $($l.remaining) left"
    if ($l.nextResetTime) { $line += ', resets ' + (Format-Reset $l 'ddd MMM dd HH:mm zzz') }
    $line
  }
}

FAQ

Should I switch from a Claude subscription to the z.ai GLM Coding Plan?

Try it before deciding. claude-z runs alongside your normal claude, so you can give both the same tasks and compare. The main differences are the model (GLM-5.3 instead of Claude), the usage limits, and who processes your code. Everything else in Claude Code works the same.

How do I get a GLM Coding Plan?

Subscribe on z.ai, then create an API key in your account. If you sign up through an invite link such as this referral link, z.ai's campaign rules (October 2026) give new subscribers 10% off their first GLM Coding Plan order.

Can I use Claude Code without a Claude subscription?

Yes. Claude Code can talk to any Anthropic-compatible endpoint, and z.ai runs one at https://api.z.ai/api/anthropic. With a GLM Coding Plan API key, claude-z runs Claude Code on GLM-5.3 instead of Claude. You still need Claude Code installed, but not an Anthropic account.

How do I use Claude Code with z.ai?

Point Claude Code at z.ai's Anthropic-compatible endpoint, https://api.z.ai/api/anthropic, and pass your GLM Coding Plan key as ANTHROPIC_AUTH_TOKEN. This repo wraps those settings in a claude-z command so they only apply when you want them, and your normal Claude Code login keeps working.

Why does Claude Code say "Model glm-5.3 isn't recognized · context assumed to be 200k tokens"?

Claude Code doesn't know GLM's context size. Use the model names with the [1m] suffix (glm-5.3[1m], glm-5.3-flash[1m]) and set CLAUDE_CODE_AUTO_COMPACT_WINDOW=1000000. Claude Code then reports a 1,000,000-token context window. If it says the [1m] model doesn't exist, run claude update.

Does GLM-5.3 get the full 1M context in Claude Code?

Yes, with the [1m] model names. Tested on Claude Code 2.1.301 and later, which report contextWindow: 1000000 for glm-5.3[1m]. Without the suffix, Claude Code assumes 200k and compacts the conversation far too early.

How do I check my z.ai GLM Coding Plan quota?

Three ways: the status line at the bottom of claude-z, the zai-usage command in any terminal, and /zai-usage inside a session. All three read z.ai's quota endpoint, https://api.z.ai/api/monitor/usage/quota/limit, and show the 5-hour and weekly credit limits with reset times in your local time zone. That endpoint isn't in z.ai's public docs. On my Pro plan in October 2026 it reported 12,000 credits per 5-hour window and 60,000 per week.

How do I check quota when the limit is already used up?

Use zai-usage in a terminal, or /zai-usage inside claude-z. A normal slash command would fail, because it sends its output to the model, and the model is what's blocked. This repo's /zai-usage is answered by a local UserPromptSubmit hook instead, so it never calls the API.

What does error 1310 "Weekly/Monthly Limit Exhausted" mean?

Your plan's weekly credit limit is used up, and z.ai returns HTTP 429 until it resets. Claude Code may retry for a while, which looks like a hang. The reset time in z.ai's message is China Standard Time (UTC+8). zai-usage shows the same reset time converted to your local time.

Does web search work in Claude Code with z.ai?

Not the built-in one: Claude Code's WebSearch tool runs on Anthropic's servers. This setup blocks it and adds z.ai's web-search-prime and web-reader MCP servers instead. z.ai charges 1.2 credits per search or page read, according to its plan overview.

Can I keep my Anthropic Claude subscription alongside z.ai?

Yes. claude keeps using your Anthropic login and ~/.claude. claude-z uses z.ai and its own ~/.claude-z folder, with separate settings, history and MCP servers. Nothing is shared between them.

Where is my z.ai API key stored?

In ~/.config/zai/api_key, with permissions limited to your user (chmod 600 on Linux/macOS, an owner-only ACL on Windows). claude-z reads it at launch and passes it to Claude Code and the z.ai tools as environment variables. The MCP config only contains the ${ZAI_API_KEY} placeholder.
